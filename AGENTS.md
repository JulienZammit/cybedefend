# AGENTS.md

This repository ships an open source AppSec platform (scanners, dashboard, policies) and a skill for coding agents.

- Install the skill: `npx skills add CybeDefend/cybedefend`
- One command: `/cybedefend` (see `skills/cybedefend/SKILL.md`)
- MCP server: 21 tools to read, triage and close findings and to read policies
- Scope: the repository you are working in, nothing else
